# Dopamine - v2.4.0 Feature Drop

### ✨ NEW STICKY MESSAGES FEATURE

This feature lets you set up sticky messages which always stay at the very bottom of a text channel.

* **HOW IT WORKS**
    * Use the `/sticky panel setup` command to setup a panel.
    * Add only text, or image, or both!

The best part? Unlike other bots, you can create as many as you want, completely for free! That's Dopamine for you!

* **SENDING PANELS**
    * Use the `/sticky panel send` command to send it in any channel you want!

* **MANAGING STICKY PANELS**
    * Use the `/sticky panels` command to see all your panels.
    * See important information such as its name, the content, etc.
    * Easy delete the panel when you don't need it anymore
