# v4.0.0 - The SuiteCASE Update

It's here. The wait is finally over. Over three months in the making, The SuiteCASE Update is here! Called so because it updates the suite (of features) and introduces cases! Here's what's new:

---

## Moderation

### Brand New Infraction Cases System

Originally suggested by **@voidxb** on Dopamine Studios' Discord server ([join here!!](https://discord.gg/XxJ6SYwHky)), we have completely rebuilt how warnings and punishments are tracked, making it much easier to manage your community's troublemakers using the new Case system. Every single infraction is a case that can be individually viewed, deleted, and reverted!

* **Detailed Records:** The bot now tracks every single point/warning in an independent database.
* **New Commands:**
    * `/case history <user>`: View a user’s complete disciplinary history, including who punished them, why, points given, and the outcome.
    * `/case view <id>`: Look at the details of one specific infraction.
    * `/case delete <id>`: Wipe a specific case, with the option to reverse the punishment as well.
    * `/case all`: All cases in the server, with a button to turn it into a live leaderboard.


### Pending (the feature due to which the update was *almost* called The Pending Update)
Instantly place a user into a long timeout while staff review evidence, stopping them from causing further issues.
* `/pending`: Add a user to the pending list.
* `pending-list`: View the list of pending users, remove them from the list, or resolve it with a punishment with a single button.
### Other Improvements to Moderation Experience
* Improved log message formatting.
* Made a mistake? You now get temporary "Undo Action" buttons directly under the bot's response whenever you use `/warn` or `/point`.
* Staff members can no longer punish anyone who holds a role equal to or higher than their own.
* We have added a "Total Decayed" stat line inside the `/warnings` or `/points` command so you can see how many points have naturally dropped off over time.
* Now checks if it actually has permissions to punish the target user before adding anything to the database.
* Fixed the Moderation Dashboard text to accurately reflect the 5-strike logic instead of the old 12-strike rules.
* If the bot fails to send a direct message to a punished user (e.g., if their DMs are closed), it will now explicitly notify your staff.

## Brand-new Data Management System
View, manage, and delete all of your User and Server data! Export your data as a Markdown and JSON file, delete individual types of data by type, and more. Truly an updated to the suite of features. Along with this, it also automatically deletes server data 30 days after Dopamine is removed from the server, and disables features in case the required channel or server can't be found or the bot is removed from them.

---

## Other Feature Updates
* **AFK System:** Simplified by removing the "role" picking menu, now automatically listens to and adds all role pings to database (when the user has the role of course) but only sends the AFK status message if the role has less than 3 users, to avoid spam when the role clearly isn't personal.
* **Notes:** Added undo button.
* **Embed Creator:** The bot will now prevent you from accidentally trying to send an embed to a category instead of a text channel.
* **Welcome & Goodbye:** You can now directly upload a card custom background using Discord UI through modals instead of using image pastebin type of websites. The UI to change channel for both has also been improved.
* **Autoreact:** Fixed a bug where the bot would silently fail if you used standard Discord formatting text (like `:slight_smile:`) instead of a native emoji. Thanks to **@kieran_laurea** for reporting the bug on Discord, the fix had already been backported to v3.9.0 over a month ago but finally is being mentioned in the changelog.
* Haiku Detection is now **on** by default (you can opt-out in settings).
* Factorial Detection is now **off** by default (you can opt-in in settings).
* Added dynamic star/skull emojis to Starboard and Skullboard that change based on total number of reactions.
