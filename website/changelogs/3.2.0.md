# v3.2.0 - Message Reporting, Selfpurge, and Bug Fixes.

### New Features

* **Message Reporting:** Integrated a new Message Reporting system into Dopamine's moderation suite. use `/moderation dashboard` -> click `Message Reporting` to open the dashboard for it.

* **Selfpurge:** (OPT-IN ONLY) Allow non-moderator members to purge their own messages less than 14 days old. Includes a mandatory buffer period of 24 hours after they run `/selfpurge start`, and messages will only be purged after 24 hours. Mods can cancel a user's selfpurge using `/selfpurge modcancel`. For this feature to be used, **an admin must first manually run `/selfpurge enable**. This feature is disabled by default for obvious security reasons.

### Bug Fixes

* Fixed goodbye messages completely.
* Fixed handling of avatars with transparent pixels in welcome and goodbye cards.
* Fixed fonts in both welcome and goodbye cards.
* Autopublish no longer ignores messages from bots and webhooks.
* Fixed command ID in alert notification.
