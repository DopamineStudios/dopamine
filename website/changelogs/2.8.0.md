# Dopamine - v2.8.0 Feature Drop

### ✨ BRAND-NEW MEMBER TRACKER FEATURE

* Tracks the number of members in your server, and sends a message in a channel of your choice when it updates!
    * `/membertracker enable` to enable.
    * `/membertracker enable` to disable.

* Set member goals and make the bot show the remaining amount in the same message!
    * `/membertracker set goal` to set a goal.
    * The goal will automiatically be cleared when it's reached.

* Fully customize the message that it sends!
    * `!!member_tracker_format` to customize the format.
    * `/membertracker set color` to change the color of the embed that it sends.

### 🐛  BUG FIXES

* There was no way to add a line break when setting up a Sticky Panel because Discord slash commands don't support it. Now, you can use \n to add them.
