# v4.3.0 - The Updates' Update?

Dopamine has been updated!

...But more importantly, **the update cycle has also been updated.** We are shifting to a rolling release cycle where changes, features, and fixes are pushed or implemented as soon as they are ready (thanks to hot reloading using Beacon), with a suummary for the changes made in that time-frame, accompanied by a version bump once every week or every other week.

### What this means for you:
* New features and fixes will come faster.
* The changes you suggest, the problems you report will all be implemented much sooner, usually less than a week's time.

This change has been done to shift away from a corporate style rigid update cycle which doesn't let small changes be added as soon as possible, to one built for the community.

Anyways, here's the summary for everything changed within the last 7 to 10 days.
