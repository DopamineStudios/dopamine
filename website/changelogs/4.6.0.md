# v4.6.0 - UI Enhancements & Refinements

Dopamine has been updated with a series of improvements, UI refinements across cogs, and stability fixes. Here's what's new:

## New Features & Improvements
### UI & Components V2
* Implemented dual-purpose Page X of Y jump-to-page buttons across cogs where pagination was missing.
* Refactored [`cogs/autoresponse.py`](https://github.com/DopamineStudios/dopamine/blob/main/cogs/autoresponse.py#L126) and [`cogs/moderation.py`](https://github.com/DopamineStudios/dopamine/blob/main/cogs/moderation.py#L304) to use Beacon Framework's standard confirmation and destructive confirmation views.
* Migrated hardcoded command mentions to Beacon Framework's dynamic command parser (`parse_command_links`) in [`cogs/afk.py`](https://github.com/DopamineStudios/dopamine/blob/main/cogs/afk.py#L3), [`cogs/alerts.py`](https://github.com/DopamineStudios/dopamine/blob/main/cogs/alerts.py#L6), and [`cogs/nickname.py`](https://github.com/DopamineStudios/dopamine/blob/main/cogs/nickname.py#L3).

### Alerts
* Updated [`cogs/alerts.py`](https://github.com/DopamineStudios/dopamine/blob/main/cogs/alerts.py#L1) to make `/alert` output ephemeral and limited reminder notifications to once per alert.

### Starboard & Skullboard
* Updated [`cogs/starboard.py`](https://github.com/DopamineStudios/dopamine/blob/main/cogs/starboard.py#L1) and [`cogs/skullboard.py`](https://github.com/DopamineStudios/dopamine/blob/main/cogs/skullboard.py#L1) to show the user mention next to the star/skull count instead of the channel mention.

## Fixes & Changes
* Exempted passive background services from automated deactivation.
* Fixed database table migration and starboard/skullboard message forwarding in [`utils/database.py`](https://github.com/DopamineStudios/dopamine/blob/main/utils/database.py#L74).
* Automatically create the database directory if it doesn't already exist.
* Relocated assets into their own dedicated [`assets/`](https://github.com/DopamineStudios/dopamine/tree/main/assets) folder.
* Updated team section and cleaned up outdated installation documentation on the website ([`website/index.html`](https://github.com/DopamineStudios/dopamine/blob/main/website/index.html)).
