# Dopamine - v2.5.0 Feature Drop

### ✨ NEW AUTOREACT FEATURE

This feature lets the bot automatically react to messages in a channel!

* **HOW IT WORKS**
    * Use the `/autoreact panel setup` command to setup a panel.
    * Give it a name, then choose the emoji it should react with.
    * Start the panel using `/autoreact panel start`, and then specifying a channel.
    * Stop it temporarily using `/autoreact panel stop`, or delete it permanently using `/autoreact panels`, then clicking on the delete button.

* **EXTRA MODES**
    * Member-whitelist mode: Only reacts to messages sent by specific user(s).
    * Image-only mode: Only reacts to messages that contain an image.

* **EXTRA INFO**
    * You can only set up three panels per server, because this feature is extremely resource intensive as it checks for new messages constantly.
    * This feature is only available to users who vote for the bot on https://top.gg. Click [here](https://top.gg/bot/1411266382380924938/vote) to vote!
