# Dopamine - v2.6.0 Feature Drop

### ✨ NEW HAIKU DETECTION FEATURE

This feature enables the bot to detect Haikus in messages, and automatically reply with the message formatted as a Haiku.

* **HOW IT WORKS**
    * Use `/haiku detection enable` and choose a channel where you want it to detect Haikus^
    * The bot will automatically reply whenever it detects a Haiku. It's constantly checking for new messages!
    * When you want to disable it, simply run `/haiku detection disable`.

* **EXTRA INFO**
    * ^Haiku detection is available in one channel only, per server. This is to combat the wastage of resources, lag, and overall worse bot experience which will be resulted from constantly checking every channel in a server for new messages.
    * This feature is only available to users who vote for the bot on https://top.gg. Click [here](https://top.gg/bot/1411266382380924938/vote) to vote!
