# Dopamine v2.13.0 Update (Back-end)

### This update includes extensive optimization, future proofing, and misc. fixes.

* Performance optimizations:
    * Connection pooling.
    * WAL (write ahead logging) mode allows concurrent reads and writes, faster writes, and safety from corruption during crashes.
    * Indexing for all databases and caching improvements.
    * All databases now are asynchronous instead of synchronous.

* Other optimizations

* Misc. bug fixes
