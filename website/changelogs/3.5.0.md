# v3.5.0 - The Autoresponse and Embed Update

### New Features

* **Autoresponse:** Sends a custom response based on a trigger you define. Supports both embeds and normal text messages. Case sensitivity can be customized. Supports the following modes: Exact match, partial match, fuzzy match. Use `/autoresponse` to get started!
* **Embed Creator:** Create custom embeds right within discord! Use `/embed` to get started!
