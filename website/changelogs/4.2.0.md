# v4.2.0 - The UI Update

Dopamine has been updated! The UI has received multiple improvements, including more consistency across features, simpler to use, and easier to scan. Here's everything that's new! Some of these features have already been added to the bot across the previous two weeks using hot-reloading, thanks to [Beacon Framework!](https://beacon.dopaminestudios.in/) (i paid *myself* for this sponsor spot)

---

## New Features
### Moderation
* Implement a new setting to enable or disable medals next to user's names in `/case users` command, thanks to @voidxb on Discord for the suggestion.
* New option to search by case ID in All Cases page.
* Add live mode to all cases page.
### Welcome/Goodbye
* Add dynamic text scaling to welcome and goodbye cards.
### Purge (`/purge`)
* Add optional reason to purge command.

---

## Improvements & Fixes
### General UI Improvements Across The Entire UI
* Update all "Return/Back to [name of page]" button labels to simply "Back" to make UI cleaner, easier, and more consistent. Also add back emoji for all buttons.
* Improve the UI for giving feedback on why you removed the bot from your server.
### Moderation
* Update simple mode definition and info in settings page.
* Update info about the feature in dashboard main page.
* Improve active infractions and all cases page sorting option names. Rename buttons and add separator to all cases page to make it more consistent with all infractions page.
* Change string to f-string in options for all infractions page to fix option rendering.
* Remove useless back button in All Cases Page.
* Fix error: Ignoring exception in command all: 'Points' object has no attribute 'get_all_infractions'
### Giveaways
* Improve option names in giveaway template browse page, made them more consistent with the rest of the bot's UI.
* Fix Giveaway participants button.
### Purge (`/purge`)
* Improve log formatting.
### Welcome/Goodbye
* Offload welcome/goodbye card generation off the main thread.
### Misc. Backend Changes
* Improve bot owners UI for managing cat pics.
* Add small delay to between each post in daily cats to avoid API rate limits.
* Add a way for bot owners to see removal feedback responses.
* Increase max number of database backups from 1 to 10.
