# Dopamine - v2.21.0 Feature Drop

This feature drop contains a brand-new moderation feature, Nickname Moderator.

* ✨ **NEW MODERATION FEATURES**:
    * **Main Dashboard**: Manage Nickname Moderator feature and find all info using `/nickname moderator panel`.
        * Choose to use either Symbol Filter (filters non-standard symbols), Profanity Filter (filters profanity), or both!
        * Customize the placeholder (the text that will replace the nickname if it contains profanity or non-standard symbols) and set any text you want.
    * **Verification**: allows you to make a member be ignored by the moderation.
        * Use `/nickname moderator verify` to add a member to the list. Use the same command to un-verify a member.
        * Use `/nickname moderator verified` to see the list of verified members in the server.
    * **Server-wide Scan**: Initiate a manual server-wide scan using `/nickname moderator scan`.
        * Dopamine will scan the display name of all members in the server and update them as needed according to your server's settings for Nickname Moderator.
    * **Logging**:
        * The bot has the ability to log all actions related to Nickname Moderator in a specified channel. To enable it, set a logging channel using `/setlog`.
