# Dopamine - v2.7.0 Feature Drop

### ✨ NEW NOTES FEATURE

This feature allows you to store notes, and access then anywhere^, any time. No limits - you can store as many notes as you want!

* **HOW IT WORKS**
    * Use `/note create` to store a note, and give it a name.
    * Use `/note fetch` followed by its name, to retrieve the note.
    * Use `/note delete` followed by the name of the note you want to delete, to permanently delete it.

* **EXTRA INFO**
    * ^You will need to add the bot to your account to be able to use this feature everywhere, including servers which don't have the Dopamine bot.
    * This feature is only available to users who vote for the bot on https://top.gg. Click [__here__](https://top.gg/bot/1411266382380924938/vote) to vote!
