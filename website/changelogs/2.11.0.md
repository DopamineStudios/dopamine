# Dopamine - v2.11.0 Update

This update includes optimizations, fixes, improvements to the user experience, and quality-of-life improvements. This changelog will be divided into the changes for each respective feature.

---

* **Auto-react**
    * `/autoreact panel setup`
        * The command now includes the parameter `channel`.
        * It now supports the ability to add multiple emojis (upto three, per panel). The bot will react to messages with emojis in the exact order you type them in.
        * Panels are now started automatically upon creation with the command.
    * `/autoreact panel start` and `/autoreact panel stop`
        * Completely removed the embed UI for choosing which panel to start/stop. Instead, a parameter has been added to the commands themselves, which shows the list of available panels automatically using slash command auto-complete.
        * Removed the `channel` parameter from the start command.
    * `/autoreact panels`
        * Removed the delete button from the embed of this command.
    * New `/autoreact panel delete` command
        * Delete a panel more easily. It lists the names of available panels using slash command auto-complete.
    * New `/autoreact panel edit` command
        * Edit the emoji(s), channel, and name of an auto-react panel.

---
* **Notes**
    * `/note create`
        * Now opens a UI instead of relying on the parameter field for the name and contents of the note.
    * `/note fetch` and `/note delete`
        * Uses dynamic auto-complete and lists the names of the available notes.
    * New`/note list` command
        * Lists the names of all the available notes.
---

* **Member Tracker**
    * Removed the following commands:
        * `/membertracker set goal`
        * `/membertracker set embedcolor`
        * `!!member_tracker_format`
    * The functionality of the removed commands has been replaced by a single, new `/membertracker edit` command.
        * The command opens a UI to customize all settings of the member tracker feature.
    * You can see the documentation of the format customization using `/membertracker info`.
    * New `/membertracker reset` command
        * This command resets all user customizations and reverts everything to default by deleting the whole table of the respective server from the database.
---

* **Scheduled Messages**
    * `/scheduledmessage panel setup` command
        * This command now opens a window where you can enter the name, the frequency, and the message itself.
    * `/scheduledmessage panels` command
        * The delete button has been removed.
    * `/scheduled message panel start` and `/scheduledmessage panel stop` commands
        * The embed UI for picking a panel to start/stop has been removed.
        * It has been replaced with slash dynamic auto-complete.
    * New `/scheduledmessage panel delete` command to replace the removed delete button.
---
* **Sticky Messages**
    * `/sticky panel setup` command
        * This command now only requires a name and channel parameter.
        * All message configuration (title, description, image, etc.) has been moved to a modal window that opens after entering the name and channel.
    * `/sticky panels` command
        * The delete button has been removed from the embed.
    * `/sticky panel start` command (renamed from `/sticky panel send`)
        * The channel parameter has been removed.
        * The embed UI has been removed.
        * It has been replaced with slash dynamic auto-complete for selecting the panel by name.
    * New `/sticky panel stop` command
        * This command stops an active sticky panel.
    * New `/sticky panel delete` command
        * This command completely deletes a sticky panel from the database.
        * Replaces the delete button that was previously in the panels embed.
    * `/sticky panel modes` command (replaces `/sticky mode imageonly` and `/sticky mode memberwhitelist`)
        * This new unified command allows you to configure both image-only mode and member whitelist mode.
---
* **Other Updates:**
    * New `/latency info` command to see advanced latency information.
    * Misc. QOL improvements, fixes, and patches.
