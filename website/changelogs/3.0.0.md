# v3.0.0 - Dopamine, Reborn.


v3.0.0 is the biggest update in Dopamine's history. Here's what's new, and what's changed:

### New Features

* **Brand new Giveaway system**: Most advanced Giveaway system across all Discord bots. Includes complete customization of the giveaway, and a template repository system where you can create, share, and publish giveaway templates. Use templates to quickly create a giveaway.

* Diagnostics and monitoring tools are re-vamped. New `/latency graph` command to generate a graph of the API latency. `/ping` and `/latency info` have been unified into just `/ping`.

* **Welcome Feature:** Completely re-vamped with new dashboard, ability to customize text, customizable welcome card, and more.
* Goodbye Feature: Same as welcome feature, but for goodbyes.
* Skullboard: "Hall of shame" equivalent of starboard.
* Bot now runs on [Dopamine Framework](https://github.com/likerofturtles/dopamine-framework).


### Changes to Existing Features and Performance Improvements

* Deprecated prefix commands.
* Almost every single feature has been re-written.
* New Components V2 dashboards for all relevant features. Deprecated multiple confusing commands and unified everything into dashboards.
* Switched to write-through caching for all features. Deprecated TTL caching.
* Customization improvements across the board for all features.
* Completely cleaned up and re-vamped `main.py`. Moved all features into their own cogs, including moderation.
* **Moderation:** 
  * Added ability to create custom actions with custom durations, and to delete existing ones. 
  * New simple mode that replaces "point" with "warn" across the whole feature, including command names. 
  * Added ability to customize decay frequency and number of points given to a user upon joining after un-ban.
* **Autoreact:**
  * Removed 3 panel limit.
  * Drastically improved UI, including new dashboard.
* **Sticky Messages:**
  * Added conversation detection.
  * Added ability to ignore bot's messages.
* **Repeating Messages:**
  * Renamed scheduled messages feature to repeating messages (because it works on frequency, not defining a specific time).
* **Haiku Detection:**
  * Overall improvements to ability to detect Haikus.
  * Haiku Detection now works across all channels in a single server, not only in a single channel.
* **Notes:**
  * Added ability to edit notes through `/note edit`.
* **Performance Improvements:**
  * Reduced memory usage by upto 5 to 10 times.
  * Autocompletes will work much faster thanks to caching.
  * Better performance across the board.
