# v4.4.0 - The Datadash Update

Dopamine has been updated, and this one is *massive*. Multiple big changes have been made to database to make the bot safer, faster, and more reliable; along with a couple of new features!

Does the "dash" after "data" stand for the database being fast, or for something else entirely that starts with the letters "dash"? Does it mean nothing or is it a teaser of a specific big update? Nobody knows! But **mark you calendars for 30 August 2026**. Here's a summary of what's changed in the last few weeks:

## New Features & Changes
### Database
* Migrated the entire database to a cloud provider (Turso) so that user and server data remains safe; no worries about data corruption.
* Consolidated all data into a single database instead of multiple fragmented DBs.
* Centralised database connection and management into a dedicated database manager.

### Daily Cat Pics
* Added credits to the provider for each picture so that in the future, users can request their own pictures to be added and they will be distinct from the ones added by me (Smite).
