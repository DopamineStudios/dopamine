# v4.5.0 - Starboard Overhaul

Dopamine's starboard and skullboard features have been overhauled. Here's what's new:

## Starboard/Skullboard Overhaul
* Replaced custom embeds with native Discord message forwarding to preserve all parts of the original message and its formatting.
* Updated to use a two-part layout (status count message + forwarded reference message).
* Implemented star/skull duplication prevention (user data for the same can be deleted from the Data manager).

## Fixes
* Fix 23 hour increment in Daily Cat Pics.
* 10 other fixes that have already been deployed, read Git commit history to learn more.
