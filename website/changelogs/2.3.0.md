# Dopamine - v2.3.0 Feature Drop

### ✨ NEW SCHEDULED MESSAGES FEATURE

This feature lets moderators set up automatic messages that repeat on their own, whether it's daily, weekly, monthly, or whenever you choose. It’s great for announcements, reminders, and keeping your community active without needing to post manually.

* **HOW IT WORKS**
    * Use the `/scheduledmessage panel setup` command to setup the message.
    * Give the message a name (for easier identifying), and enter how often it repeats, and where it's sent.
    * Enter the message you want the bot to send.

The best part? Unlike other bots, you can create as many as you want, completely for free! That's Dopamine for you!

* **MANAGING MESSAGES**
    * Use `/scheduledmessage panels` to see all your setup messages.
    * See important information such as it's name, the content, how often it repeats, where it's sent, etc.
    * Easily delete the message when you don't need it anymore.
