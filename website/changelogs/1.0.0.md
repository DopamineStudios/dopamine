# v1.0.0 Release

I'm proud to announce that the Dopamine bot is finally in the Release stage! This is a moderation and utility bot developed by me.

## __Key Features:__

* Point-based moderation system.

* Automated point-decay system to ensure that users aren't on "thin ice" if they aren't punished for a long time.

* Comprehensive logging for all actions.

* Rich embed-based responses for everything to ensure a smooth and easy user experience.

* Automatic message deletion for moderator commands.

* Cooldowns for all non-moderator commands to safeguard against spam and abuse.

## __Other Features:__

* DMs sent to members upon punishment.

* Welcome and message purge features.

* Interactive and comprehensive help system.

## __Final Additions and Changes:__

## NEW `temphide` COMMAND

* Send a hidden message that will be revealed upon clicking the reveal button.

* 60-second cooldown to avoid spam and misuse.

This release marks the beginning of a great Discord Bot! My plan and promise is that this bot will always stay 100% free of charge and will never be monetized. This is a project for me to express my creativity and to give back to the Discord community, not to make a quick buck.

I hope Dopamine makes managing your servers easier, smoother, fun, and more cute! Here’s to the first of many releases, and to a bot that grows with its community!
