# Dopamine - v2.19.0 Update

### This update contains extensive optimizations of the whole bot, which is an attempt to refine all existing code before v3 *(wink wink)* and make the bot ready for much higher workloads.

* ⚡ **Key Optimizations**:
    * Connection pooling for all relevant features
    * Caching frequently used data from DB
    * Batch processing of background tasks
    * Command logic refactoring
    * ...and much more!

* ✨ **New Features**:
    * __NEW ALERTS FEATURE__
        * Developers can push alerts, that users can view using `/alert` (This changelog has also been pushed through the new alerts feature!)

These changes aim to the make the bot much more efficient.
