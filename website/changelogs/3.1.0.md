# v3.1.0 - Suddenly Factorial & Autopublish Features, Bug Fixes & Performance Improvements.

### New Features

* **Suddenly Factorial:** Factorials are underappreciated and often ignored. That's why, the bot now automatically detects messages that contain an exclamation `!` mark after any number, and automatically replies with the factorial of that number; like a true nerd. This feature is opt-out. Use `/factorial` to toggle between `enabled` and `disabled`.

* **Autopublish:** Discord announcement channels are great, but having to click the `Publish` button for EVERY. DAMN. MESSAGE. is so annoying! That's why you can now set up auto-publish for any announcement channel. Get started with `/autopublish enable`.

### Bug Fixes

* Fixed edit button (My Templates -> Edit) sending giveaway as ephemeral.
* Fixed API latency cache freezing.
* Fixed version not being updated upon bot restart by refreshing version.
* Fixed member position permanently being stuck at 1 or 2 in welcome feature.
* Fixed goodbye/leave messages never sending.

### Performance Improvements and Misc. Changes

* Refactored all cogs to fallback to API fetch if user, guild, or channel objects aren't in cache.
* Refactored welcome feature to use pyvips instead of pillow due to the former offering much better performance.
* Refactored goodbye to use pyvips instead of pillow due to the former offering much better performance.
* Added new function to ensure that default simple mode is applied for every guild that runs any moderation command for the first time.
* New reload_me.py dev-only cog to reload config.py and .env for updates.
