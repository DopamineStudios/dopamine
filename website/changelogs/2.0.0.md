# Dopamine - v2.0.0 Release

### ✨ NEW FEATURES

* **FULLY CUSTOMIZABLE POINTS SYSTEM**
    * 12 Default actions, going from warning to permanent ban.
    * You can assign any value to each of them and have a personalized moderation experience. Use `/pointsview` to get started!

* **SLASH COMMANDS FOR EVERYTHING**
    * All commands now support slash commands. No need to use the old prefixes anymore!

##  📈 IMPROVEMENTS AND BUG FIXES

* Welcome messages are no longer enabled by default upon inviting the bot to a server.
* Various other quality-of-life improvements.
