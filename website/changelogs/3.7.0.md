# v3.7.0 - New AFK Feature!

### New Features
* **AFK:** Exactly what it sounds like! Run `!!afk` or `/afk` to go AFK, and whenever someone mentions you, they will be notified that you're AFK with an optional status message! Dopamine can also save all messages where you were pinged, and show them to you when you come back!

### Updates & Changes
* Added reason to bot-wide ban for users and guilds.
* Updated logic of the message sent when the bot is invited to a server.
* Updated default welcome text.
* Reduced Line 1 font size in goodbye card.
* Added "Alert from the Developer at Dopamine Studios" to the top of alert embed.
* Added text colour customization to welcome and goodbye cards.
* Dopamine now sends a DM to a user when they are banned from using the bot.

### Bug Fixes
* Fixed prefix commands not working (they were indented inside another command wtf 😭)
* Fixed /purge error where the bot would keep thinking forever even after deleting messages.
* Fixed uptime monitor.
* Fixed daily words not sending.
* Fixed daily images not sending consistently.
* Fixed Fuzzy mode false positives in Autoresponse by using `ratio` instead of `partial_ratio`.

### 🪦 Discontinued

* **The Chat/Ask Dopamine feature has been discontinued**. The AI model did not meet my expectations. It was so small that it would keep hallucinating, mostly about being able to control anything in Discord (even though the AI can't). Moreover, it was also a bit too slow to be fit for mass scale use. I have no plans for the foreseeable future to bring this feature back.
