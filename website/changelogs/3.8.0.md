# v3.8.0 - Improved Giveaway Experience!

### Updates & Changes

* Updated defaults in welcome and goodbye features.
* Updated placeholders in welcome and goodbye features.
* Re-named Dashboard class from CV2Helper to WelcomeDashboardView for consistency.
* Added ability to select multiple Giveaway winner roles.
* Updated /giveaway create to send the message as non-ephemeral instead of ephemeral.
* Improved Giveaway search UI by adding header that shows the current query string.
* Giveaway Browse page now sorts by "Most Popular" by default.
* Giveaway Browse page dropdown to select sort mode now shows the current sort mode as selected, instead of generic placeholder: Sort by....
* Removed Giveaway embed colour from Giveaway Browse Page and My Templates page.
* Updated /invite command to use Components V2.
* Improved Step 4 UI of Autoresponse creation wizard.
* Renamed the "Fuzzy Matching" bullet point to "Fuzzy Match" for consistency.
* Improved Haiku detection: Integrated 'inflect' library, added slang handling, added digit handling, and improved abbreviation handling.

### Fixes

* Fixed error in /giveaway reroll command.
* Fixed bug in Winner role select where it would always show the required roles as winner roles if required roles are selected regardless of what role you select in dropdown, or completely crashes if no required roles.
* Fixed bug in giveaway preview timeout. Message is now successfully edited to display that the preview has expired.
