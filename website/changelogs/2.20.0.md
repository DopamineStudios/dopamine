# Dopamine - v2.20.0 Feature Drop

This feature drop contains a brand new feature for managing slowmode in Discord servers.

* ✨ **NEW SLOWMODE FEATURES**:
    * You can now schedule slowmode to be enabled during specific times of the day! Use `/slowmode schedule start` to get started.
    * You can delete all slowmodes for a channel using `/slowmode schedule delete` command.
    * Along with these, there is a third command `/slowmode configure` to manually enable to disable slowmode in a channel.

* **OTHER CHANGES**:
    * Internal code changes (minor refactoring of cogs for better maintainability)

* **EXTRA INFO**
    * The new feature is only available to users who vote for the bot on https://top.gg. Click [__here__](https://top.gg/bot/1411266382380924938/vote) to vote!
