# Dopamine - v2.1.0 Feature Drop

### ✨ NEW STARBOARD & LFG FEATURES

* The bot now supports a starboard feature! The bot will send a message that reaches the required ⭐ reaction threshold into the starboard channel, which can be set using `/starboard set channel`.
    * Star count will be updated automatically when more people react to the message with the ⭐ emoji.

* Looking For Group feature (`/lfg create`) that creates a post to which people can react to, and when it reaches the threshold for reactions, everyone who reacted to the post will be mentioned automatically. in the same channel.

* The threshold for starboard can be adjusted with `/starboard threshold`, and that for LFG can be adjusted with `/lfg threshold`.
